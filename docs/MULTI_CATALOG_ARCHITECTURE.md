# AI Manager 2.4.11 — единая версия, единый OEM-каталог

## Единый продукт и версия

AI Manager — один продукт. Клиентский чат, административная панель, API, аналитика, база данных и интеграционные модули выпускаются одной версией. Единственный источник версии — `backend/VERSION`; API `/health` возвращает её для отображения во всех интерфейсах.

Не вести независимые номера версий для frontend, backend, admin или каталогов.

## Единственный каталог запчастей: TradeSoft OEM Parts.Catalogs

TradeSoft — единственный подключаемый источник VIN-определения и подбора запчастей.

Поддерживаемый поток:
1. Получить VIN от клиента и проверить формат.
2. Запросить TradeSoft VIN / CarInfo.
3. Требовать однозначный автомобиль и OEM catalogue identity (`catalogId` и `carId`).
4. Получить автомобиль, каталожные группы и оригинальные схемы.
5. По выбранной группе или запросу получить детали, OE-номера и callout/позиции схем.
6. Если TradeSoft вернул неоднозначность, неполный идентификатор или ошибку — остановить подбор и сообщить о проблеме. Не подменять ответ сторонним декодером и не придумывать применимость.

API-ключ хранится только на backend в `TRADESOFT_API_TOKEN`; браузер его не получает. Включение интеграции: `TRADESOFT_ENABLED=true`.

## Запрещённые fallback-источники

SoloCatalog и NHTSA не являются частью интеграции AI Manager. Не подключать их, не отправлять им VIN или поисковые запросы, не использовать как резервный источник и не показывать в интерфейсе. Не хранить их ключи/URL в переменных приложения.

## Административная аналитика

Аналитика PostgreSQL показывает реальные события API и TradeSoft: запросы, длительность, ошибки, историю диалогов и неполные попытки подбора. Успешный заказ, продажа и стоимость токенов AI отображаются только после подключения достоверных событий из соответствующих бизнес-процессов.

## API

- `GET /health` — единая версия, состояние PostgreSQL и статус TradeSoft.
- `GET /api/catalog/v1/providers` — единственный настроенный провайдер TradeSoft.
- `POST /api/catalog/v1/vehicles/decode` — VIN через TradeSoft.
- `POST /api/catalog/v1/lookup` — группы, схемы и детали через TradeSoft.
- `GET /api/admin/analytics` — защищённая аналитика.
- `GET /api/admin/conversations` — защищённая история диалогов.

Клиентский чат и существующая лента администратора остаются частью того же приложения.
